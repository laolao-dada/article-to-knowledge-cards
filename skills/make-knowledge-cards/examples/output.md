## 卡片 1：费曼技巧的定位

- **核心知识**：费曼技巧是用自己的话讲清楚知识、而非死记硬背的理解型学习方法。
- **简明解释**：它把"能否讲明白"作为是否真懂的检验标准。
- **例子 / 自测**：自测——"为什么能背下公式不等于真懂？"

## 卡片 2：第一步——选定并写下概念

- **核心知识**：先选一个要学习的概念，并把它写下来作为起点。
- **简明解释**：明确对象才能围绕它组织讲解。
- **例子 / 自测**：例子——想搞懂"通货膨胀"，先把它写在一张纸顶部。

## 卡片 3：第二步——对外行讲解

- **核心知识**：假装教给完全不懂的外行，用最通俗的语言解释。
- **简明解释**：通俗化会暴露你含混的地方，逼你真正理解。
- **例子 / 自测**：自测——"如果你只能用术语解释，算讲清楚了吗？"

## 卡片 4：第三步——卡壳就回头补

- **核心知识**：讲解中卡壳或说不清时，回到资料补齐薄弱环节。
- **简明解释**：卡壳处正是理解漏洞，针对性回看比通读更高效。
- **例子 / 自测**：例子——讲到"为什么加息抑制通胀"卡住，就专门补这块。

## 卡片 5：第四步——简化与类比

- **核心知识**：简化语言、打类比、去掉术语，让解释更易懂。
- **简明解释**：能类比说明，代表你抓住了本质而非表象。
- **例子 / 自测**：例子——把"电流"类比成"水管里的水流"就是一次简化。
